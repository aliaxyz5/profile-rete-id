## ✨ Fitur Unggulan

1. **Three.js Avian 3D Boids Canvas**: Kawanan burung terbang dinamis dengan kepakan sayap dan respon interaksi kursor mouse di Hero Section.
2. **Animasi Origami Unfold pada Navbar**: Ikon burung origami geometris bersudut lipatan kertas (*crease facets*) yang mekar lembut saat tautan menu diarahkan kursor (*hover*).
3. **Kursor Logo Awan Mini**: Penunjuk kursor awan interaktif bergaris origami dengan pendar biru langit.
4. **Ekosistem Suara Alam (Web Audio API)**: Sintesis prosedural desau angin sejuk pegunungan dan kicau burung liar yang menenangkan.
5. **Indikator 24 Jam Biru Langit**: Denyut status aktif nonstop 24 jam dengan nuansa biru langit cerah.
6. **Integrasi Google Maps & Salin Alamat**: Peta lokasi presisi Kedunggalar Ngawi dan tombol salin alamat langsung ke *clipboard*.
7. **Pusat Kontak Cepat WhatsApp**: Form pesan cepat dan floating button yang terhubung otomatis ke nomor resmi.

## 🛠️ Teknologi & Framework

- **Frontend**: React 19 + TypeScript + Vite
- **Styling**: Tailwind CSS v4 + Custom Glassmorphism
- **3D & Animasi**: Three.js (Avian Boids) + Motion + Procedural Web Audio API
- **Icons**: Lucide React + Custom Geometric Origami SVGs

## 🚀 Menjalankan Secara Lokal (Local Development)

```bash
# 1. Clone repository
git clone https://github.com/<USERNAME>/<REPO_NAME>.git
cd <REPO_NAME>

# 2. Install dependencies
npm install

# 3. Jalankan server lokal
npm run dev
```

Buka peramban di `http://localhost:3000`.

---

## 📦 Build Produksi & Deploy ke GitHub Pages

Untuk membuat berkas statis siap pakai:
```bash
npm run build
```

Berkas produksi akan tersimpan di dalam folder `dist/`.

Proyek ini telah dilengkapi alur otomatis **GitHub Actions** (`.github/workflows/deploy.yml`). Saat Anda melakukan push ke branch `main`, GitHub Pages akan membangun dan menayangkan website secara otomatis!
